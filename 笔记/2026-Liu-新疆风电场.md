# Liu 2026 · 新疆大型风电场通过改变降水促进区域绿化

## 基本信息

| 项 | 内容 |
|---|---|
| 英文标题 | Large-scale wind farms in Xinjiang would promote regional greening by shifting precipitation |
| 作者 | Xiaoning Liu, Yujie Yang, Zhengyao Lu, Yan Liu, Wei Huang, Jie Chen |
| 期刊 | Environmental Research Letters, 21 (2026) 134036 |
| DOI | 10.1088/1748-9326/ae7fa2 |
| 方法 | WRF 4.2.2（Fitch 2012 风机参数化）+ LPJ-GUESS 动态植被模型，离线双向耦合 |
| 研究区 | 塔里木盆地风电场 TLM-WF（38–41°N, 77–88°E）、准噶尔盆地 ZGE-WF（43–46°N, 84–90°E） |
| 模拟时段 | 2019-12-01 — 2020-12-31，预热 1 个月 |
| 一句话 | 建大规模风电 → 风速降 → 上风区降水增（最大 +92.11 mm/yr）、下风绿洲降水减 → 植被变绿 |
